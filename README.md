# 🤖 ANNA

Asistente virtual desarrollado en Python inspirado en JARVIS de la película IRON MAN.

## Funciones

- 🎤 Reconocimiento de voz
- 🗣 Síntesis de voz
- 🌐 Navegación web
- 💻 Apertura de aplicaciones
- 🔎 Búsquedas en Google
- 🤖 Preparado para IA
- 🖥 Interfaz gráfica moderna

## Tecnologías

- Python 3.13
- SpeechRecognition
- pyttsx3
- CustomTkinter
- Pygame
